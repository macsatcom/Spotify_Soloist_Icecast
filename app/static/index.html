    Connect Spotify Web API (for search & library)

    2. Add the redirect URI http://127.0.0.1:8888/callback exactly, and save.

    How to pair

    1. Create an API key at developer.spotify.com/dashboard/soloist (Premium account) and save it under Settings.
    2. Open the Spotify app on a phone or computer on the same network.
    3. Open the device picker and choose Soloist. The session is stored and survives restarts.

    Re-pair replaces the stored session, for example to switch account. Soloist stops, waits for you to select the device in the Spotify app (up to 5 minutes), then restarts.
